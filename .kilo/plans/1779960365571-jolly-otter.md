### 3. System message handling (important detail)

The system prompt the user supplied contains:

- The literal token `{{Today}}` at the top
- Many backticks (```html`, `` ` ``, code fences) inside the prompt body

Because `systemMessage` is a template literal (backtick-delimited string), we must escape all internal backticks as `` \` `` and escape `${` if present. The `ProcedureCreator` entry already demonstrates this pattern (see `src/data.ts:189` where `` \`\`\`markdown `` is used inside a template literal).

Template tokens used by Big-AGI's prompt mixer (`{{Today}}`, `{{LocaleNow}}`, `{{LLM.Cutoff}}`, `{{RenderMermaid}}`, etc.) are passed through as-is and resolved at runtime - so `{{Today}}` in the user's prompt will Just Work.

Concretely the implementation will:

1. Wrap the entire Dutch prompt in `` ` ... ` `` backticks.
2. Replace every literal `` ` `` inside the prompt (including the three-backtick code fences inside the HTML/PLAIN templates) with `` \` ``.
3. Replace any `${` (none expected in this prompt, but a safety check) with `\${`.
4. Keep `{{Today}}`, `{{LocaleNow}}`, etc. unchanged so the prompt mixer can substitute them.

No other characters need escaping.

### 4. (Optional, recommended) Drop the redundant `Datum:` line

The user's prompt starts with `Datum: {{Today}}`. Big-AGI's prompt mixer already auto-substitutes `{{Today}}`, so this line works as-is. We keep it verbatim - it's harmless and was explicitly provided.
